# pans

#### 介绍
多Reactor-多线程-多协程服务器框架

## 代码规范
常量：全部大写 
类名：首字母大写，驼峰 
非静态成员函数：首字母小写，驼峰 
静态成员函数：首字母大写，驼峰 
非静态成员变量：以m_开头，首字母小写，驼峰 
静态成员变量：以s_开头，首字母小写，驼峰 
全局函数：首字母大写，驼峰 
函数参数：小写，下划线隔开 
局部变量：小写，下划线隔开


## 文件夹说明
docs : 存放文档性内容
        * 维护 README 等说明文档
        * 重点：维护 中文版 Readme

tests : 测试程序
    * 验证代码的正确性与健壮性
    * 与核心代码分离存放

tools : 非核心但重要的工具
    * 承担重要辅助功能
    * 例：Excel 导表工具

cmake : CMake 公共代码
    * 存放函数等公共 CMake 代码
    * 独立存放，供 CMakeLists.txt 包含
    *  CMake : 跨平台开源构建工具
    * 本身**不编译**，只生成各平台构建文件
    * 生成目标：`Makefile` / `sln` / `Ninja`
